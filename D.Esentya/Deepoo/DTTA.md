## **2. ARCHITECTURE TECHNIQUE : LE TOKEN DE VALIDATION “TRUTH BEACON” (T.B.)**

### **A. Le Truth Beacon Token (TBT)**

- **Type :** RWA NFT dynamique (Real World Asset).
- **Fonction :** Valide un événement IRL via un combo **QR Code + Truth ID + Géoloc + Timestamp + Biométrie sonique**.
- **Émission :** Un TBT est minté pour chaque quête validée.
- **Utilisation :**
  - Débloque du contenu dans **D.Quest** (le jeu vidéo DTC).
  - Donne accès à des **Karma BOTs** pour gérer une ferme à distance.
  - Augmente le **Karma PK (Physique)** et **IK (Intellectuel)**.

### **B. Mécanisme de Validation (Exemple : L’Annapurna avec D.Crocus)**

1. **Scan QR** au départ du trek → Truth ID vérifié.
2. **Checkpoints géolocalisés** (automatiques via app DTTA) :
   - Camp de base
   - Sommet secondaire
   - Village d’aide communautaire
3. **Preuve d’action régénérative** :
   - Photo du rocher secret en plongée (géotaggée, hashée sur IPFS).
   - Signature numérique des villageois aidés (via **D.Wallet** locale).
4. **Mint du TBT** “Annapurna Guardian” :
   - Donne accès au **Karma BOT “Yeti Farmer”** dans D.Quest.
   - Débloque un **avatar exclusif “Sherpa Numérique”**.
   - Valide le passage **Sadhaka → Eternal Sadhaka**.
